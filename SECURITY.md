# Security

Report vulnerabilities privately to contact@aiamatrix.com, including reproduction steps and the affected version. Do not include real credentials or customer data. This new project has no promised response SLA; the latest release is the supported version once published.

The validator intentionally requests submitted and linked URLs. Use trusted inputs or a runner with outbound network restrictions. Do not run it with access to sensitive internal services when processing untrusted files. Timeouts, bounded concurrency, redirect limits and response-size limits reduce resource use but are not a network security boundary.

No telemetry is collected. Do not publish secrets in fixtures, logs, issues, or pull requests.
